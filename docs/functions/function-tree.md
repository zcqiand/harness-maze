# 功能清单（Function Tree）— harness-maze（像素迷宫竞速）

> **全体系唯一锚点。** 需求、流程、设计、测试都引用这里的 ID。
> 不在这里的 ID 是悬空引用。**改功能，先改这份表。**

## 编号规则

| 层级 | 名称 | 格式 | 含义 |
|---|---|---|---|
| 一级 | 功能模块 | `M01` | 业务域边界 |
| 二级 | 功能 | `M01.F01` | 一个完整业务步骤 / 独立闭环流程 |
| 三级 | 功能子项 | `M0x.F0y.I0z` | 技术交付单元，对应一个核心函数、页面组件或交互入口 |

**硬规则**

1. 编号单调递增，永不复用。废弃改状态，不删行。
2. 子项编号必须以父级为前缀。
3. 拆不出子项的功能 → 它其实是子项，往上并。

**状态**：`规划` | `开发中` | `已上线` | `已废弃`
**子项类型**：`页面` | `标签页` | `查询` | `按钮` | `报表` | `接口`
**交付**：`仅前端` | `前端+后端` | `仅后端`（本仓为纯前端 React 单页，全部 `仅前端`）
